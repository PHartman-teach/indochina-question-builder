INDOCHINA QUESTION MACHINE & ESSAY PLANNER — v1.0

Open index.html for the combined workshop, questions.html for question generation, or planning.html for planning. All files work locally without an internet connection.

The generator uses the approved 48-question reference bank, additional reviewed practice questions and a curated bank of valid historical templates. It does not randomly mix incompatible actors, events or outcomes. The planner offers three broad thesis approaches and syllabus-area evidence prompts, not verified sources or bespoke AI essays.

The Official HSC collection is deliberately empty until verified official questions are supplied. Do not present newly authored practice questions as NESA questions. The generator uses default section weights 10/20/45/25, which can be edited.

The Russia v7.4.2 interface and workflow informed this edition; this is a distinct Indochina implementation, not a feature-for-feature copy (no online ratings, Supabase, or imported official examination question corpus). Existing Russia apps are unchanged.

Version 1.2: Detailed syllabus filtering. Generate from preferences supports 15 individual syllabus dot points and six key features, as well as sections and question families. Multiple selected dot points or features are OR within each group; dot point and feature groups combine with AND. Unrestricted random ignores these filters. If nothing matches, a clear message is shown rather than silently ignoring selections. Existing saved preferences are preserved.

Version 1.3: Relationship-graph engine with explicit factor-to-outcome relationships, bounded factor comparisons, change/continuity and effectiveness questions. Existing 522 constrained questions retained as fallback. Graph questions prioritised in normal generation. No arbitrary cross-topic mixing. Full app's generated collection includes relationship questions.
